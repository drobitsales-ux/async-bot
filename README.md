# async-bot

Торговый и исследовательский бот для крипто-фьючерсов (BingX). Сейчас — режим ожидания, торговли нет: поиск стратегии закончен без доказанного преимущества.

- `START_HERE.md` — краткий вход для человека и новой ИИ-сессии.
- `PROJECT_HANDOFF.md` — полное досье (хронология, все гипотезы, метод, шаблон новой идеи).
- `BOT_SPEC.md` — источник истины (разделы §2.x — результаты и пре-регистрации).
- `RESEARCH_SUMMARY.md` — итоги исследовательской фазы.
- `CLAUDE.md` — контекст для Claude (частично устарел, см. BOT_SPEC).
